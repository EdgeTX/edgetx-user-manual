# Global Functions

**Global functions** are special functions that apply to all models on the Radio. They are configured exactly as model **Special Functions**, and most of the same functions are available. A few, however, are model and hardware capability dependent and cannot be used as Global Functions - for example, **Adjust**, **Override**, and **Push CS**. For more information about configuring Global Functions, refer to the [Special Functions](../model-settings/special-functions.md) section as they are otherwise essentially the same.
